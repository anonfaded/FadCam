# Fad Playout

Fad Playout will turn scheduled programmes and live events into continuous virtual TV channels.

## Required behaviour

1. Load an ordered channel schedule.
2. Resolve the current programme.
3. Start the selected media source.
4. Allow an authorized live override.
5. End the override safely.
6. Resume the schedule at the correct point.
7. Publish programme state to Fad EPG and FadPlay.

No viewer-facing player should depend on the playout process's internal address.
