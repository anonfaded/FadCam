# FadPlay

FadPlay is the worldwide audience layer for the Fad TV ecosystem.

## First release scope

- live channels
- video on demand
- programme guide
- channel pages
- search and discovery
- watch history
- resilient playback

FadPlay consumes public application APIs. It must never connect directly to private MediaMTX, FFmpeg, or MinIO infrastructure.

The first client target is web, followed by Android/Android TV using the same versioned contracts.
